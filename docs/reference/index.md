# Reference

The contracts. Everything on these pages is stable: finding codes are never renumbered or reused,
exit codes never change meaning, the JSON payload carries its own version, and the context schema
declares its own version in the manifest. The
[compatibility policy](/reference/compatibility) states exactly what that promise covers.
