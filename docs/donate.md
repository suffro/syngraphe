# Donate

Syngraphe is free, open source and Apache-2.0 licensed, and it stays that way. If it saved you
time, you can support the work here.

Two places, either is fine:

- **[GitHub Sponsors](https://github.com/sponsors/suffro)** — monthly or one-off, billed through
  the GitHub account you already have.
- **[Ko-fi](https://ko-fi.com/suffro)** — one-off, card or PayPal, no account needed. The frame
  below is that same page, embedded.

Payments are handled entirely by GitHub or Ko-fi. Nothing you enter there reaches this site.
