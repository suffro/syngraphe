# The Name

**Syngraphe** comes from the Ancient Greek **συγγραφή** (*syngraphḗ*), built from **σύν**
(*syn*, "together") and **γράφω** (*gráphō*, "to write"): literally, *writing together*.

The word carries three meanings, and each one describes the project.

## Written together

The context does not belong to one person, one tool or one vendor's cloud. Humans and coding
agents write it together and read the same documents in `.context/`.

## A written contract

In Athenian law, a *syngraphḗ* was a contract set down in writing and agreed by the parties — a
document that held on its own, independent of whoever drafted it. The context works the same way:
stable rules in `AGENTS.md`, canonical truth in `.context/`, and deterministic checks through
`syngraphe check`. And like that contract, it stays valid without its author: the repository remains
complete and meaningful even if Syngraphe itself disappears.

## A historical record

From the same root comes *syngrapheús*, the prose writer or historian — the word Thucydides used for
himself. `.context/` reads like the chronicle of a project: `truth/` for how it is, `state/` for
what is happening now, `decisions/` for why, and `history/` for what came before, with Git keeping
time.

---

A document written by many hands, binding as an agreement and kept as memory — inside the
repository, not anywhere else.
