# Getting Started

Syngraphe is a small, Git-native command-line tool that creates and validates a `.context/`
directory of Markdown documents describing what a repository is, how it is built, and what is
happening in it right now — and points every coding agent at those documents through `AGENTS.md`.

Start with the first page if you have never seen it, or jump straight to the
[quickstart](/getting-started/quickstart) if you want it running in the next two minutes.
